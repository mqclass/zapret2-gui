# Гайд по редизайну UI zapret2-gui

Этот файл — бриф для работы над новым интерфейсом (в том числе для ИИ-агента в Antigravity). Ветка для работы: `feature/ui-polish`.

## Статус (2026-10-22)

Antigravity у владельца не загрузился, поэтому редизайн выполнен силами Muse в этой же ветке, по этому же брифу:

- Итерация 1 (44d8199): новая дизайн-система (токены, дуотон-акцент, радиусы), фон реагирует на состояние движка, переходы между экранами на framer-motion, переработанный дашборд и HeroOrb.
- Итерация 2: стеклянные секционные карточки на всех экранах, фикс обрезки заголовков в диагностике (бейдж статуса переехал в подвал карточки), hover-lift снова работает на карточках со stagger-появлением.
- Итерация 3 (по замечаниям владельца): тема перекрашена из синей в фиолетово-чёрную (акцент violet, второй акцент fuchsia, логотип в той же гамме); macOS-«светофоры» заменены на оконные кнопки в стиле Windows справа в шапке; исправлена овальная иконка Telegram (у чипа не было shrink-0, его сжимал флекс-ряд; заодно защищены все аналогичные чипы); заголовок вкладки в шапке больше не клиппится по высоте.
- Итерация 4 (по замечанию владельца): убраны декоративные подписи: «DPI Bypass Utility» в сайдбаре и подзаголовки вкладок в шапке, остался только заголовок.

Каждая итерация: tsc + production build, скриншоты всех экранов на headless-стенде со стабом Tauri, независимое ревью. Ветка ждёт проверки владельцем и решения о слиянии в dev.

## Что это за приложение

zapret2-gui — приложение для Windows (Tauri v2 + React 18 + TypeScript + Tailwind CSS 3) для обхода блокировок сайтов в России, движок zapret2 (DPI-обход). Аудитория — обычные люди, не технари. Главный принцип продукта: «бабушка разберётся». Одна большая кнопка «Включить обход», человеческие слова, ноль технического жаргона в интерфейсе.

## Задача

Полностью переработать UX/UI: внешний вид, компоновку, анимации, ощущения от приложения. Должно стать красиво, современно и плавно. Логику работы и контракт с бэкендом при этом не ломать.

## Карта фронтенда

- `src/App.tsx` — каркас приложения, глобальный стейт движка, опрос статуса
- `src/components/` — TopBar (своя шапка окна), Sidebar, HeroOrb (главная кнопка), StrategySelector, LogViewer, баннеры и модалки
- `src/components/views/` — 8 экранов: Dashboard (главный), Strategies (стратегии), Telegram (мост), DnsSpeed (DNS и скорость), Lists (списки), Diagnostics (диагностика), Logs (логи), Settings (настройки)
- `src/i18n/` — все тексты интерфейса, три языка: ru (основной), en, uk
- `src/types/index.ts` — типы данных контракта с Rust-бэкендом
- `src/index.css`, `tailwind.config.js` — стили и дизайн-токены

## Жёсткие ограничения (нарушать нельзя)

1. **Контракт с бэкендом.** Не переименовывать и не удалять вызовы `invoke("...")` и имена их аргументов, не менять поля в `src/types/` без согласования. Это API между фронтом и Rust (79 команд). Нужен новый вызов — сначала спросить владельца.
2. **Не трогать `src-tauri/`** (Rust-код) вообще.
3. **Окно без системных декораций** (`decorations: false` в конфиге Tauri). Свой TopBar с кнопками свернуть / развернуть / закрыть и перетаскиванием окна обязан остаться рабочим.
4. **Все тексты только через i18n** (`t.*`), сразу в трёх языках. Никаких захардкоженных строк в компонентах. Тексты писать как человек: просто, без канцелярита, без длинных тире.
5. **Сохранить ключевые сценарии:** включение обхода в один клик с главного экрана; мастер «Что хотите разблокировать?» на экране стратегий; понятный статус (работает / выключен / ошибка); живой пинг до YouTube и Discord.
6. **Анимации — на framer-motion**, он уже в зависимостях. Новых тяжёлых библиотек без нужды не добавлять.
7. **Размеры окна:** основное 1050×760, минимальное 850×620. Вёрстка не должна разваливаться на минимуме.

## Что можно и нужно менять

- Цветовую систему, типографику, сетку, отступы, радиусы, тени, градиенты
- Микроанимации: переходы экранов, hover/press состояния, анимацию главной кнопки и статусов, скелетоны загрузки
- Компоновку экранов, если сценарии из п. 5 ограничений сохранены
- Иконки (lucide-react уже подключён)

## Дизайн-направление

Сейчас приложение — тёмное стекло (glassmorphism). Можно развивать эту тему или предложить новую, но: тёмная тема обязательна (приложением пользуются вечером, оно про «включил и забыл»), акцентный цвет должен читаться как «безопасно / работает» для статуса обхода. Избегать кислотных цветов и перегруза эффектами: красота тут — это спокойствие и ясность, а не фейерверк.

## Проверка перед пушем

1. `npm run build` зелёный (это tsc + vite build)
2. Коммиты осмысленные, пуш в `feature/ui-polish`
3. Написать владельцу «готово» — дальше ревью кода, проверка экранов по скриншотам и слияние в dev делает Muse
